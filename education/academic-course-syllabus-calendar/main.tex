% --- Course Description & Objectives ---
\section*{\faBook\ Course Overview \& Objectives}
CS 402 provides an in-depth study of distributed algorithms, cloud infrastructure design, and scalable system architecture. Students will explore fundamental principles governing consensus, fault tolerance, replication, and distributed storage. Hands-on laboratory assignments will focus on building robust services using modern microservices design patterns.

Upon successful completion of this course, students will be able to:
\begin{enumerate}[label=\textcolor{TealSecondary}{\bfseries \arabic*.}, leftmargin=2em]
  \item Analyze and apply classic distributed consensus protocols such as Raft and Paxos.
  \item Architect fault-tolerant storage engines leveraging consistent hashing and event-driven messaging.
  \item Evaluate performance trade-offs under CAP theorem constraints and eventual consistency models.
  \item Deploy and monitor containerized microservices across cloud clusters using modern orchestrators.
\end{enumerate}
