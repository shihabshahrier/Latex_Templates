# LaTeX Templates for Theses, Papers, CVs and Presentations

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates) [![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE) [![Templates](https://img.shields.io/badge/templates-232-success.svg)](https://letx.app/templates)

**232 free LaTeX templates** across 19 categories — university theses, journal articles, CVs and résumés, academic posters, Beamer presentations, lab reports, grant proposals and formal letters. All compile-tested and ready to edit.

Every template is compile-tested, MIT-licensed, and free to use — no account, no signup, no paywall. Open one in the browser to edit and compile it without installing LaTeX, or clone the repo and run `latexmk` locally. The full library of 601+ templates lives at [letx.app/templates](https://letx.app/templates).

## How to use a template

**Online (no install):** click *Open in LetX* on any template below. It opens ready to edit, compiles to PDF in the browser, and supports real-time collaboration with co-authors.

**Locally:**

```bash
git clone https://github.com/shihabshahrier/Latex_Templates.git
cd Latex_Templates/<category>/<template>
latexmk -pdf main.tex     # check metadata.json for the right compiler
```

Each template directory contains `main.tex`, a compiled `main.pdf`, a `preview.png`, and a `metadata.json` naming its compiler (`pdflatex`, `xelatex` or `lualatex`).

## Frequently asked questions

### What is in this repository?

232 free, MIT-licensed LaTeX templates organised into 19 categories — university theses, journal articles, CVs, posters, presentations, lab reports and more. Every one compiles as-is.

### Can I use these without installing LaTeX?

Yes. Each template links to an online version at letx.app that opens in the browser, compiles to PDF, and supports real-time collaboration — no local TeX installation needed.

### Which university thesis templates are included?

Thesis and university formats are grouped under [`universities/`](#university--thesis-templates), covering formats from institutions in several countries. The wider library at [letx.app/templates/universities](https://letx.app/templates/universities) carries considerably more.

### How do I contribute a template?

Add a directory under the matching category containing `main.tex`, `metadata.json` and a compiled `main.pdf`, then open a pull request. University thesis formats are the most useful contributions.

Templates are organised as `<category>/<template-slug>/`. To add one, create a directory under the right category containing `main.tex`, `metadata.json`, and a compiled `main.pdf`. Open a pull request — contributions of university thesis formats are especially welcome, since those are the hardest for students to find.
