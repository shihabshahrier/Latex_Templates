# Project Gantt Timeline

Project Gantt Timeline LaTeX template — gantt chart latex template. Elegant, compile-tested, editable online at letx.app.

**Category:** tech docs

## Features
- Elegant, modern design
- Compile-tested
- Fully editable sample content

## Compile
```
latexmk -pdf main.tex
```
Compiler: pdflatex

## Edit online
Open and edit this template on [letx.app](https://letx.app) — free collaborative LaTeX editor.
